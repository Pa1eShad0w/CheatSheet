# 架构与验收

## 运行结构

```text
NSApplication / AppDelegate
  └─ AppController（MainActor）
       ├─ AppModel：设置、Accessibility 信任状态、SMAppService
       ├─ CommandHold：事件 → 纯状态转换 → 副作用指令
       ├─ NSEvent global + local monitor：不读取字符，不吞事件
       ├─ MenuReadSession → MenuReader：等待期间后台读取，仅读取 AX 属性
       └─ OverlayController → 非激活 NSPanel → SwiftUI OverlayView
```

Swift Package Manager 管理应用和核心模块；不依赖工程生成器、外部包或手工维护的 Xcode project。`Package.swift` 声明 Swift 6 工具链模式与 macOS 14 部署版本。应用包元数据和本地化由打包脚本安装，不依赖 `swift run` 的临时进程身份。

## 核心模块

### CommandHold

接口是事件输入与副作用输出；内部状态为 idle / waiting / visible / pinned / blocked。计时、窗口和系统事件不进入模块，因此普通快捷键、取消和生命周期变化都能不经 GUI 测试。

- 单独按下 Command：等待；等待结束：显示。
- 普通模式下 Command 松开：取消等待或隐藏。
- 点击面板左下角 ⌘：visible → pinned，松键、其他修饰键和键盘事件不再关闭，系统截图快捷键可继续送达系统。
- 固定时点击窗口外：采样实际 Command 状态并使手势失效；清除固定状态后，下一次正常长按即可触发。再次点击 ⌘ 取消固定，未按住 Command 时立即关闭。
- 输入普通键、添加其他修饰键或按下鼠标按钮：取消并锁定到 Command 松开。
- 生命周期失效事件携带当前 Command 物理状态。如果仍按着，保持 blocked，不允许在一次按住期间重新触发。
- 已按住鼠标时开始长按，由应用适配层检查并取消；显示前再次核验。

普通模式下，应用在切换前台应用、休眠、屏幕休眠、会话失活、修改设置和移除监听时使手势失效。仅在未固定面板显示期间每 120ms 核验物理修饰键、鼠标按钮和前台 PID，防止丢失松键事件后面板滞留。固定时停止该 watchdog，并忽略无鼠标点击的应用激活通知，以容纳系统截图工具；休眠、会话失活、设置和权限变化仍关闭。空闲时没有高频轮询。

### MenuReader

小接口：`read(processIdentifier:applicationName:onProgress:) throws -> MenuSnapshot`，`onProgress` 默认为 nil，原调用保持兼容。明确是阻塞调用，必须放在后台；进度回调同步发生在读取线程，只携带值快照。

实现内隐藏 AX 元素、属性类型检查、菜单分组、快捷键符号化、去重、祖先禁用状态和遍历预算。`MenuTreeSource` 是内部 seam，让真实遍历算法可以使用内存菜单树测试，不需要系统授权。

- 菜单项先读取 role，再批量获取六个字段，普通路径从七次属性读取减少为两次；容器只读取 role。
- 批量返回中的 AX 错误值逐项校验，缺失属性保留默认处理；不支持批量或返回长度异常时退回单字段读取。真实权限/应用错误不会被伪装成空属性。
- 单次 AX 消息超时最多 0.2 秒。
- 总遍历预算约 3 秒、4,096 节点、16 层深度。
- 时间、节点或深度达到上限时返回带 `isTruncated` 的部分快照。
- 第一条可用快捷键立即发布进度，之后按约 50ms、增加 32 条或顶层组完成节流；进度非空且标记为未完整，最终返回完整/截断状态。
- 后代项的暂时不可读或失效只中止该分支，保留已读项并继续兄弟分支；根读取错误、权限错误、任意非预期错误和取消仍传播。
- 同步 AX 调用无法在执行途中瞬时取消；在调用前后检查取消状态和剩余预算。
- 不打开、激活、点击或执行菜单。按需加载的菜单可能缺失。
- 仅按完整菜单路径、命令标题和快捷键共同去重；相同键组合在不同菜单下仍保留。
- 特殊键优先使用公开字符或 glyph 信息；虚拟键只映射布局无关的功能/导航键，不假设美国键盘布局。

## 并发与结果所有权

UI、设置、监听安装与移除、手势调度都在 MainActor。`MenuReadSession` 在单独按住 ⌘ 80ms 后开始读取，与用户设置的长按等待时间重叠，而不是等面板显示后再开始。80ms 的宽限期避免对大多数正常快捷键发起不必要的读取。

菜单读取通过 `Task.detached` 执行，AX 引用不跨线程暴露。`cancel()` 仅把展示与已经开始的读取分离；尚处于 80ms 宽限期的任务仍立即取消。同一 PID/contextID 的下一次查看复用正在进行的有界读取，避免每次松键都从头开始。

成功且非空的结果在内存中最多保留一份、3 秒后清除；每次新展示仍后台重新验证，已有内容先以 provisional/truncated 状态显示。普通按键、面板外鼠标/滚动、应用切换、权限/设置变化或退出固定模式调用 `invalidate()` 并递增 contextID，硬取消工作、清除缓存。程序自动改变焦点或菜单状态且没有输入事件时，可能在背景重新验证前短暂显示旧快照；这不是永久缓存或始终实时的承诺。

渐进读取按 FIFO 发布，generation 和 attempt ID 隔离不同上下文及重试的迟到结果。只有暂时的 `menuUnavailable` 最多重试一次，延迟 100ms；权限/应用失效不重试。后续暂时失败时保留已取得的可用局部结果。整个会话另有 7 秒上限，不无限等待。

普通发布检查手势显示状态与前台 PID；固定模式允许系统截图工具激活，继续显示捕获的目标。快照使用不可变的 `Sendable` 值类型。

`MenuReading` 日志记录固定成功/重试/失败分类、耗时和数量，不记录菜单文本、应用名称或输入文字。最终失败在 error 级别记录 permission-required / application-unavailable / menu-unavailable。无实时 Accessibility 权限时，测试只能证明已复现的代码路径得到修正，不能保证特定应用的偶发故障已完全解决。

## 面板布局

按原版 `template.html` 与 nib 已确认的布局重建，取证与边界见 [layout-reference.md](layout-reference.md)。移除顶部标题区，正文与快捷键均为 13pt 原生系统字体，行高 22pt。快捷键在命令名称前的 74pt 槽内，主键占 18pt（多字符 30pt）；随后间距 4pt，名称及分组标题均从列内 x=78 开始。分组标题有 16pt 上留白，不再绘制组下横线。

左右各 16pt 留白，列间距 20pt、1pt 竖线，四列均分剩余宽度。底栏 48pt，使用独立品牌和现有设置动作；按用户新要求隐藏右下角提示，在左下角增加 ⌘ 固定按钮，固定时使用强调色。底部按钮所在面板内的鼠标操作不取消手势，外部点击仍取消；按钮不获取键盘焦点。固定窗口使用现有 floating level，不接管系统截图或拦截键盘。

内容按菜单顺序从上到下填充，再从左到右续列。每列分组独立堆叠，不使用行对齐网格；能在整列容纳的分组不拆分，跨列分组在每个续列重复标题和标题上留白，容量计算也包含这部分高度。打包算法与行高共享度量，避免纵向溢出。仅启用横向滚动；每次展示重置到首列，同一会话结果更新不重置滚动位置。

1000×620 首选窗口、屏幕约束、12pt 圆角及滚动条预留是当前原生实现的选择，不是已经证实的原版运行参数。颜色、字体栅格化、纹理及完整原版动作菜单尚未完成原版运行对照。

Rosetta 不被当作布局比例因子。视觉密度由显式字号、行高、间距和面板尺寸控制，不通过非原生缩放或缩窄字体模拟旧系统。

## 权限、存储与分发

- 显式请求 Accessibility；系统授权只能由用户完成。应用每 2 秒刷新信任状态，变化时重建监听。
- 不主动请求 Input Monitoring，不使用事件注入或修改型 event tap。
- UserDefaults 仅保存启用状态、等待时间和是否展示过欢迎界面；不保存菜单或键盘输入。
- 登录项使用 `SMAppService.mainApp`，不写 LaunchAgent plist。
- 无 App Sandbox：跨应用 Accessibility 是产品核心能力，不声称可直接上架 Mac App Store。
- 本地 ad-hoc 签名不能代替 Developer ID 和公证。重建后系统可能要求重新授权。

## 验证命令

```sh
bash scripts/check.sh                 # swift build + 核心 / AX 属性请求检查
bash scripts/check-ui.sh              # 读取会话、流式分栏、横向滚动、离屏渲染
bash scripts/check.sh --xctest        # 需要完整 Xcode 的 XCTest
bash scripts/build-app.sh             # 当前架构 release + bundle + 签名校验
bash scripts/build-app.sh --universal # Apple silicon + Intel
```

仅 Command Line Tools 环境中，`swift test` 缺失 XCTest 是工具链限制，不通过删减测试或引入伪测试框架来隐藏。核心检查直接编译真实实现，覆盖手势、键名、菜单遍历、预算、取消和批量属性读取。离屏检查使用实际界面，验证分栏无丢失/重复、长组续列、无纵向溢出、横向滚动和会话重置；使用可控读取检查提前完成、焦点变化后重读和取消结果隔离。它们不能验证系统权限或真实应用 IPC 延迟。

## 手工验收清单

以下项目需要用户在打包应用上操作；自动构建通过不代表它们已经通过。

- [ ] 从固定路径启动；菜单栏图标正常，无常驻 Dock 图标，首次打开设置。
- [ ] 首次授权、拒绝授权、撤销再授权；不授权时不会读取其他应用。
- [ ] Finder、Safari、TextEdit 分别长按 ⌘，显示对应应用名称与快捷键；松开关闭。
- [ ] ⌘C / ⌘V / ⌘Tab / ⌘⇧组合不弹出；其他键松开但 ⌘ 仍按着时不重新触发。
- [ ] 拖动或按住鼠标时再按 ⌘，不显示面板。
- [ ] 显示/加载时切应用、暂停、修改等待时间或休眠，不出现旧结果或滞留窗口。
- [ ] 面板不夺取前台应用的键盘焦点；正常桌面、全屏 Spaces、多显示器均正常。
- [ ] 四列独立堆叠，超长组向右续列且重复原组标题，横向滚动无纵向溢出；左侧快捷键与名称/标题对齐符合参考度量。
- [ ] 按住 Command 时点击底部设置按钮能够打开设置；面板外点击仍正常关闭，普通快捷键不被拦截。
- [ ] 点击左下角 ⌘ 后松键仍置顶；系统截图组合键不关闭，窗口截图可选中面板；外部点击后关闭且下一次长按立即可用。
- [ ] 再次点击 ⌘ 退出固定；设置、暂停、权限撤销和会话休眠能清除固定状态。
- [ ] 连续查看同一上下文能复用进度/短期结果；键盘输入、外部点击/滚动或切应用后不复用旧上下文。
- [ ] 输入框聚焦/失焦、选区改变后重新触发，命令状态更新；记录具体应用和读取耗时，验证无不必要的显示后等待。
- [ ] 长菜单标题、禁用命令、空结果、超时或不可访问菜单的提示正确。
- [ ] 英文和简体中文、浅色和深色、较小屏幕下设置与面板可读。
- [ ] 安全输入场景没有错误捕获或干扰；松键未送达时面板能自行关闭。
- [ ] 登录项注册、系统批准、取消注册和实际重新登录正常。
- [ ] 使用 Developer ID 分发时，公证、staple、Gatekeeper 检查及首次启动正常。
