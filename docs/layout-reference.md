## 原生列流与必要保护

内容按菜单顺序自上而下填充，再向右续列；组标题不按行对齐。根据用户对原版实际行为的确认，跨列分组在每个续列顶部**重复原组标题**，并为标题和上留白预留完整高度。此前仅凭静态 CSS 夹具推断“不重复标题”是不充分的，现已纠正；静态模板不能排除原版在运行时主动分组或插入续列标题。长名称按列边缘裁切并保留完整路径提示，不额外插入现代省略号；快捷键与名称不互换顺序。

保留此前用户要求的横向溢出及无纵向滚动。原生实现为滚动条保留 16pt 空间，避免系统设为“始终显示滚动条”时遮挡底行。原版 CSS 本身不能证明其运行时的高度约束、滚动条预留或分页策略；这些仍需运行对照。

极端测试组合 `⌃⌥⇧⌘F12` 在“现代 WKWebView＋重建 HTML”中可能出现浮动槽溢出，甚至影响邻行。这只证明参考夹具的行为，不能断言原版实际应用也如此。原生实现保留槽宽与自然字形，不复刻浮动导致的邻行错位，不缩窄字体。

底部按钮保持非激活面板内可点击。根据后续用户需求，左下角增加 ⌘ 固定按钮，右下角提示文字隐藏。普通模式松开 Command 或切应用关闭；固定模式松键和截图组合键不关闭，点击窗口外恢复普通模式。离屏测试直接调用实际 NSButton，验证设置、固定和取消固定回调；真实鼠标事件及系统截图仍需现场验收。

## 明确未做到完全一致的部分

- **品牌与署名**：不把新实现署名为 Media Atelier。底栏使用 CheatSheet Modern，并明确独立实现。
- **原资源**：不复制纸张纹理、图标或其他图片。当前使用语义纯色背景、系统 gear 图标。
- **控件功能**：原版动作菜单没有完整复刻；右侧按钮连接现有设置。左侧新增 ⌘ 固定按钮、右下角说明隐藏，是用户要求的明确改动。
- **窗口尺寸及圆角**：保留 1000×620 首选尺寸、屏幕约束及 12pt 圆角。它们不是由 nib 设计时尺寸证明的原版运行值。
- **颜色**：原版模板动态颜色占位符的完整运行映射尚未取得；使用当前系统的 control/window 背景及文本/分隔色，不冒充原版取色。
- **渲染器**：新实现是 SwiftUI/AppKit，参考夹具是现代 WKWebView，而原版依赖旧 WebView。抗锯齿、裁切及基线仍可能有差异。

参考脚本在 `.build/original-layout-reference*.json` 记录计算样式和几何信息，在对应 PNG 输出参考图。四种组合各有 16 项几何检查，包括字号、22 行高、74＋4 槽、18/30 主键槽、标题对齐、四列和列宽公式。

脚本会自行补充 HTML 外壳、固定测试高度和 `column-fill:auto`，并用当前系统语义色替换占位符。所有这些补充都是夹具假设，不是已确认的原版运行行为；参考 PNG 不包含原版底栏或窗口外观。新实现预览使用更长菜单以强制测试横向溢出，两者不应直接当作同一内容的逐像素验收图。

真正的逐像素验收仍需要：原版实际运行、同一目标应用及菜单状态、相同屏幕缩放与外观下的截图。此前只能说“按已确认的原始度量重建”，不能说“完全复制完成”。
